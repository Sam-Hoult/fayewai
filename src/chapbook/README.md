# Chapbook files

Put the chapbook here:

- `fragments-and-echoes.pdf` — the exported PDF. The reader on the Poetry page picks it up automatically.
- or `pages/01.jpg`, `pages/02.jpg`, … — one image per page, listed in `src/_data/chapbook.js`.

Nothing else needs to change.

Currently `pages/` holds the 32 pages captured from the Canva "Sample artwork" design.
Replace them — and empty the `pages` list in `src/_data/chapbook.js` — once the chapbook PDF is ready.
